Binh AI Content Manager

Binh AI Content Manager is a private content automation tool used by one individual creator to manage the creator's own channel workflow.

YouTube API Services disclosure: This application uses YouTube API Services. It is not affiliated with, endorsed by, or sponsored by YouTube or Google.

What the application does

The application verifies the authorized channel, uploads original videos created for that channel, and reads non-monetary performance analytics such as views and watch performance so future content decisions can be improved.

Google and YouTube API access

The application requests only the permissions needed to identify the authorized channel, upload new videos, and read non-monetary analytics for the owner's own channel. It does not manage third-party channels, sell access to other users, scrape YouTube, or redistribute Google user data.

Current access is limited to the scopes for YouTube account read-only access, YouTube video upload, and YouTube Analytics read-only access.

Automation workflow

The workflow may include content research, script and metadata preparation, video generation, quality checks, upload, and performance analysis. Existing videos are not automatically deleted.

Privacy and user controls

The owner can revoke the application's Google Account access at any time through Google Account permissions. See the Privacy Policy for details about data access, use, storage, retention, and deletion.
